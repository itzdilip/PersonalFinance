Google Integration

Configure your Google Cloud Project to enable cloud backups.

Google Drive Integration

To enable Google Drive backups, you need to configure your own Google Cloud Project:

  1. Go to the Google Cloud Console.
  2. Create a new project named "FinanceFlow".
  3. Go to APIs & Services > Library and enable Google Drive API.
  4. Go to OAuth consent screen, configure it, and add the .../auth/drive.file scope.
  5. Go to Credentials, create an OAuth 2.0 Client ID (Web application).
  6. Add https://your-domain.com to Authorized JavaScript origins.
  7. Copy your Client ID and replace REPLACE_WITH_YOUR_CLIENT_ID in js/app.js and index.html.
Once configured, signing in with Google will allow you to save your data directly to your personal Drive.
