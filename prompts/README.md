# Prompts Directory

This directory contains the history of prompts used to build the Kubera-Finance Flow application.

## Structure

- **[initial_request.txt](initial_request.txt)**: The original project prompt.
- **[PROMPT_HISTORY.md](PROMPT_HISTORY.md)**: A consolidated, chronological list of all prompts given to the AI.
- **[logs/](logs/)**: Individual Markdown files for each prompt, numbered sequentially.

All interactions are captured directly from the Gemini CLI session logs.
